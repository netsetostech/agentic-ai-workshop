1 The retake rule, from the source

Easy

Rs 0. Import idempotency.py, print the one line of claim() that decides a retake, and write the rule as a function. Print a table of six statuses against three callers: claim(), claim(retake=True), take_batch(). Done when the table matches step 2 of the lesson and you can name the branch of push() each refusal reaches.

  1. Put the kit root and services/ingest on sys.path and import idempotency.
  2. Find the retakes line with inspect.getsource.
  3. Write claim_wins(status, retake) and take_batch_wins(status) from what the two functions test.
  4. Print the table.

line = next((l.strip() for l in src.splitlines() if "retakes" in l), None)
print(line or "no `retakes` line: this kit copy predates 12 September 2026 - re-clone once the learner repo is rebuilt")

# 2. the same rule as a function (idempotency.claim, the `retakes` tuple and the `not in retakes` test)
def claim_wins(status, retake=False):
    retakes = ("failed", "superseded") if retake else ("failed",)
    return status is None or status in retakes

# 3. take_batch: only a queued claim (idempotency.take_batch: `snap.get("status") != "queued"` refuses)
def take_batch_wins(status):
    return status == "queued"

print(f"\n{'status':12} {'claim()':10} {'claim(retake=True)':20} take_batch()")
for status in (None, "processing", "indexed", "superseded", "queued", "failed"):
    print(f"{str(status or 'absent'):12} {str(claim_wins(status)):10} {str(claim_wins(status, True)):20} {take_batch_wins(status)}")
What you should see. First the line retakes = ("failed", "superseded") if retake else ("failed",). Then six rows: absent and failed win for both claim callers; superseded wins only with retake=True - the branch push() takes after a refused undo; processing and indexed never win (duplicates, acked); queued wins only for take_batch(), and push() acks it as queued_batch. A status that wins for take_batch() never wins for claim(), and the other way round: the two lanes cannot hold one version at once.

3 The swap and the undo on a fake Firestore

Medium

Rs 0. Run the kit's real swap_versions(), finish(), record_source(), refresh_fingerprint(), reactivate() and retire_previous() against a fake of the Firestore client - the step 9 trace of the lesson, on your laptop. Then take one row away, as the TTL policy would, and watch the undo refuse. Done when the fingerprint after C equals the fingerprint after A, and D prints reactivate_incomplete with rows 2 and chunks 3.

  1. Read the fake: it implements only what idempotency.py calls - collection().document().get/set/update, where().stream(), batch() - and honours the two sentinels the kit writes, SERVER_TIMESTAMP and DELETE_FIELD. It counts commits.
  2. Stage three rows for version 1 the way mirror_to_firestore(staged=True) does, swap, record. Stage version 2, swap, record. Reactivate version 1, retire version 2, record.
  3. Pop one of version 2's rows and call reactivate() for it.

Complete solution

python — Colab or Cloud Shell
import logging, os, sys
from datetime import datetime, timedelta, timezone
KIT = next(p for p in ("agentic-ai-weekend-gcp-learners/deploy", "agentic-ai-weekend-gcp-learners/code", "deploy", "code")
           if os.path.isdir(os.path.join(p, "services", "ingest")))
sys.path[:0] = [KIT, os.path.join(KIT, "services", "ingest")]
logging.basicConfig(level=logging.INFO, format="%(message)s", stream=sys.stdout)   # the worker's own log format
from google.cloud import firestore          # only for the two sentinels the kit writes: SERVER_TIMESTAMP, DELETE_FIELD
import idempotency as led

# ---- a fake of the Firestore client surface idempotency.py uses: collection / document / where / stream / batch ----
class FakeSnap:
    def __init__(self, ref, data):
        self.reference, self.id, self._d, self.update_time = ref, ref.id, data, None
    @property
    def exists(self):
        return self._d is not None
    def to_dict(self):
        return dict(self._d) if self._d is not None else None
    def get(self, key):
        return (self._d or {}).get(key)

class FakeRef:
    def __init__(self, coll, id):
        self._coll, self.id = coll, id
    def get(self, transaction=None):
        return FakeSnap(self, self._coll.rows.get(self.id))
    def set(self, fields, merge=False):
        row = dict(self._coll.rows.get(self.id) or {}) if merge else {}
        self._coll.apply(row, fields)
        self._coll.rows[self.id] = row
    def update(self, fields):
        self._coll.apply(self._coll.rows[self.id], fields)

class FakeQuery:
    def __init__(self, coll, filters=()):
        self._coll, self._filters = coll, tuple(filters)
    def where(self, field, op, value):
        return FakeQuery(self._coll, self._filters + ((field, value),))
    def stream(self):
        for id, row in list(self._coll.rows.items()):
            if all(row.get(f) == v for f, v in self._filters):
                yield FakeSnap(FakeRef(self._coll, id), row)

class FakeCollection:
    def __init__(self, db, name):
        self.db, self.name, self.rows = db, name, {}
    def document(self, id):
        return FakeRef(self, id)
    def where(self, field, op, value):
        return FakeQuery(self).where(field, op, value)
    def stream(self):
        return FakeQuery(self).stream()
    def apply(self, row, fields):
        for k, v in fields.items():
            if v is firestore.DELETE_FIELD:
                row.pop(k, None)
            elif v is firestore.SERVER_TIMESTAMP:
                row[k] = datetime.now(timezone.utc)
            else:
                row[k] = v

class FakeBatch:
    def __init__(self, db):
        self.db, self.ops = db, []
    def update(self, ref, fields):
        self.ops.append(("update", ref, fields, False))
    def set(self, ref, fields, merge=False):
        self.ops.append(("set", ref, fields, merge))
    def commit(self):
        for op, ref, fields, merge in self.ops:
            ref.update(fields) if op == "update" else ref.set(fields, merge=merge)
        self.db.commits += 1
        self.ops = []

class FakeDB:
    def __init__(self):
        self.colls, self.commits = {}, 0
    def collection(self, name):
        return self.colls.setdefault(name, FakeCollection(self, name))
    def batch(self):
        return FakeBatch(self)

# ---- the fixture of the main page's step 9: two versions of acme/smoke_note.md, three chunks each ----
db = FakeDB()
TENANT, NAME = "acme", "acme/smoke_note.md"
URI = f"gs://documind-ai-YOUR-ID-uploads/{NAME}"
SHA1, SHA2 = "1" * 64, "2" * 64
K1, K2 = f"{TENANT}_{SHA1}", f"{TENANT}_{SHA2}"
V1 = ["preamble v1", "SM-01 bay 4", "SM-02 ladder"]
V2 = ["preamble v2 effective 2026-10-01", "SM-01 bay 7", "SM-02 ladder"]
expire = lambda: datetime.now(timezone.utc) + timedelta(days=led.RETENTION_DAYS)

def stage(doc_key, sha, texts):
    """The rows indexer.mirror_to_firestore(staged=True) writes (lesson 3.3), minus the vector."""
    for i, text in enumerate(texts):
        db.collection("chunks").document(f"{TENANT}:{sha}#{i}").set({
            "tenant_id": TENANT, "text": text, "source_uri": URI, "doc_key": doc_key, "current": False,
            "staged": True, "expire_at": datetime.now(timezone.utc) + timedelta(days=1),
            "chunk_hash": led.hashlib.sha256(text.encode()).hexdigest(), "locator": text.split()[0],
            "embedding_model": "text-embedding-005", "embedding_version": "1",
            "embedding_task_type": "RETRIEVAL_DOCUMENT", "indexed_at": firestore.SERVER_TIMESTAMP})

def show(title):
    print(f"\n== {title}  (commits so far: {db.commits})")
    for id, r in sorted(db.collection("chunks").rows.items()):
        print(f"  {id[:12]}.. current={r.get('current')!s:5} staged={r.get('staged')} superseded_by={str(r.get('superseded_by'))[:10]} "
              f"expire_at={'set' if r.get('expire_at') else '-'} effective_to={r.get('effective_to')} reactivated={'yes' if r.get('reactivated_at') else '-'}")
    for id, r in db.collection("documents").rows.items():
        print(f"  documents/{id[:10]}.. status={r.get('status')} chunks={r.get('chunks')} retired_at={'set' if r.get('retired_at') else '-'}")
    for id, r in db.collection("sources").rows.items():
        print(f"  sources/{id} doc_key={r['doc_key'][:10]}.. gen={r['generation']} reused/embedded/retired={r['reused']}/{r['embedded']}/{r['retired']}")

# A. version 1 in: staged, then the swap (nothing to retire), the claim, the ledger row, the fingerprint
stage(K1, SHA1, V1)
gone = led.swap_versions(db, TENANT, URI, K1, expire_at=expire())
led.finish(db, K1, 3, {"reused": 0, "embedded": 3}, "g1")
led.record_source(db, TENANT, NAME, URI, K1, "g1", SHA1, 3, None, reused=0, embedded=3, retired=0,
                  embedding_model="text-embedding-005", embedding_version="1")
f1 = led.refresh_fingerprint(db, TENANT, "ingest_ok")
show("A: version 1 swapped in")

# B. version 2 in: the carry-over (3.3) would reuse SM-02's vector; the swap retires version 1
stage(K2, SHA2, V2)
gone = led.swap_versions(db, TENANT, URI, K2, expire_at=expire(), effective_to="2026-10-01")
led.finish(db, K2, 3, {"reused": 1, "embedded": 2}, "g2")
led.record_source(db, TENANT, NAME, URI, K2, "g2", SHA2, 3, "2026-10-01", reused=1, embedded=2,
                  retired=gone["retired_chunks"], embedding_model="text-embedding-005", embedding_version="1")
f2 = led.refresh_fingerprint(db, TENANT, "ingest_ok")
show("B: version 2 swapped in, version 1 retired")

# C. version 1 again: the undo - counted, dated, flipped; then the newer version retired
back = led.reactivate(db, TENANT, URI, K1)
gone = led.retire_previous(db, TENANT, URI, K1, expire_at=expire())
led.record_source(db, TENANT, NAME, URI, K1, "g3", SHA1, back, None, reused=back, embedded=0,
                  retired=gone["retired_chunks"], embedding_model="text-embedding-005", embedding_version="1")
f3 = led.refresh_fingerprint(db, TENANT, "ingest_reactivated")
show("C: version 1 reactivated, version 2 retired")
print(f"\nfingerprints: A={f1} B={f2} C={f3}  (C == A: {f3 == f1})")

# D. the refused undo: pretend the TTL policy has taken one of version 2's rows, then ask for version 2 back
db.collection("chunks").rows.pop(f"{TENANT}:{SHA2}#1")
print("\nD: reactivate(K2) with one row gone ->", led.reactivate(db, TENANT, URI, K2))
What you should see. After A: three rows current=True, no staged, no expire_at, one commit. After B: version 1's rows current=False with superseded_by=acme_22222, expire_at set and effective_to=2026-10-01; version 2's rows current; documents/acme_11111 is superseded with retired_at set; the ledger row says reused/embedded/retired=1/2/3; two commits. After C: version 1 current again with reactivated=yes and its four retirement fields gone, version 2 retired with superseded_by=acme_11111 and no effective_to, the ledger row back on acme_11111 at generation g3 with 3/0/3, four commits. The line fingerprints: ... (C == A: True): the same set of current keys, the same hash. Then D: a reactivate_incomplete line with "rows":2,"chunks":3 and the reason fewer rows than the claim counted, and the call returns None - nothing was flipped.

Challenge

Complete solution

What you should see. Step 1: a reconcile_withdrawn line with retired_chunks 3, the fingerprint moved, and the note that the object is kept. Step 2: one plan line withdrawn acme/smoke_note.md withdrawn, object kept, and reconcile_done with "withdrawn": 1 counted beside a drift that does not include it. Step 3: ingest_withdrawn with the hint make restore SOURCE= clears the tombstone - the claim was refused, the tombstone held, nothing moved. On a lane where the rows had expired you would see ingest_ok instead, a fresh version - --restore moves the row to retired first precisely so that either path, or a lost event, recovers.

print("  b.md, same sha as the ledger      ->", decide_bytes("s2", "acme", ledger["acme~b.md"], documents))
print("  b.md, a new sha                   ->", decide_bytes("s8", "acme", ledger["acme~b.md"], documents))
print("  new.pdf, sha of an indexed claim  ->", decide_bytes("s9", "acme", None, documents))
print("  big.pdf, sha of a queued claim    ->", decide_bytes("s7", "acme", None, documents))

summary = {"retire": 1, "reingest": 1, "backfill": 1, "touch": 0, "ok": 1, "withdrawn": 1, "queued": 1}
print("\ndrift for that night:", drift_of(summary), "(withdrawn and queued are decisions, not drift)")
What you should see. Seven actions: ok a.md; check_bytes b.md (generation 5 to 8); check_bytes new.pdf (not in the ledger); withdrawn kept.md (withdrawn, object kept); queued big.pdf (the batch job's); and, from the ledger's side, retire gone.md (gone from the bucket). After hashing: touch when the sha is the ledger's own, reingest for a new sha, backfill for a sha an indexed claim already holds, queued for a sha the batch lane holds. Drift 3 - one retire, one reingest, one backfill - with the withdrawn source and the queued document counted beside it, not in it. That is the number alerts.tf pages on when it stays above zero for two nights.
