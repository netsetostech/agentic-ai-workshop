2 Refuse at the gate

Easy

Rs 0. Build the object record Cloud Storage publishes, validate it with IngestMessage, then break it four ways and read the field each error names.

  1. Validate a record with contentType spelled the API's way and size as a string of digits.
  2. Break it: .. in the name, a name at the bucket root, a size of zero (what make poison uploads), a missing generation.
  3. Print e.errors()[0]["msg"] and the field for each.

Complete solution

python — Colab or a laptop
# Exercise 2 - refuse at the gate (Rs 0; runs after exercise 1)
import json
from pydantic import ValidationError
from contracts import IngestMessage

record = {"bucket": "documind-ai-YOUR-ID-uploads", "name": "acme/hr_policy_2026.md",
          "size": "160949", "contentType": "text/markdown", "generation": "1758400000000000"}
msg = IngestMessage.model_validate_json(json.dumps(record))
print("accepted:", msg.tenant_id, msg.gcs_uri, msg.size, type(msg.size).__name__)

cases = {"traversal": dict(record, name="../zeta/secret.md"),
         "bucket root": dict(record, name="hr_policy_2026.md"),
         "zero bytes (make poison)": dict(record, size="0"),
         "no generation": {k: v for k, v in record.items() if k != "generation"}}
for label, bad in cases.items():
    try:
        IngestMessage.model_validate_json(json.dumps(bad))
        print(f"{label:26}: ACCEPTED - that is a bug")
    except ValidationError as e:
        err = e.errors()[0]
        field = ".".join(str(x) for x in err["loc"]) or "model"
        print(f"{label:26}: refused - {err['msg']} (field: {field})")
What you should see. accepted: acme gs://documind-ai-YOUR-ID-uploads/acme/hr_policy_2026.md 160949 int - the string size became an int. Then traversal: Value error, object name escapes its prefix on name; bucket root: Value error, object is not under a tenant prefix on the model (the after-validator sees the whole record); zero bytes: Input should be greater than or equal to 1 on size - the line that makes make poison a 400; no generation: Field required. Each refusal names its field, which is the point of validating at the edge.

3 Move a clause, then change it

Medium

Rs 0. Copy plan_carry_over out of indexer.py, build the held map from revision 1's hashes, and run the plan under four edits: the demo's revision 2, two sections swapped, a new section at the top, one paragraph re-wrapped. Then chunk both revisions with windows() alone and count the reuse under the old fixed-window rule.

  1. Copy the function with its line number; never import indexer.
  2. held maps hash to vector - any vector; the plan only asks whether the hash is there.
  3. Print chunks, reused, embedded and the misses' locators for each edit.

Complete solution

python — Colab or a laptop
# Exercise 3 - move a clause, then change it (Rs 0; runs after exercise 1)
from contracts import chunk_hash

# services/ingest/indexer.py, line 94 - copied: indexer.py builds a genai client at import
def plan_carry_over(chunks, held):
    vectors, misses = [], []
    for index, chunk in enumerate(chunks):
        vector = held.get(chunk.get("chunk_hash") or "")
        vectors.append(vector)
        if vector is None:
            misses.append(index)
    return vectors, misses

v1 = open(os.path.join(EVALS, "corpus", "acme", "hr_policy_2026.md"), encoding="utf-8").read()
v2 = open(os.path.join(EVALS, "demo", "hr_policy_2026_v2.md"), encoding="utf-8").read()
doc = {"slug": "hr_policy_2026", "doc_type": "policy", "source_uri": "gs://b/acme/hr_policy_2026.md", "text": v1}
current = dc.chunk_document(doc, "acme")
held = {c["chunk_hash"]: [0.0] * 768 for c in current}          # what held_vectors() returns: vectors by hash

def report(label, text):
    chunks = dc.chunk_document(dict(doc, text=text), "acme")
    _, misses = plan_carry_over(chunks, held)
    print(f"{label:30} chunks={len(chunks)} reused={len(chunks) - len(misses)} embedded={len(misses)}",
          [chunks[i]["locator"] for i in misses])

a, b, c = v1.index("## NP-03"), v1.index("## PB-02"), v1.index("## LV-01")
report("revision 2 (the demo file)", v2)
report("NP-03 and PB-02 swapped", v1[:a] + v1[b:c] + v1[a:b] + v1[c:])
report("a new section at the top", v1[:a] + "## WFH-01 - Work from home\n\nTwo days a week, with written approval.\n\n" + v1[a:])
report("one paragraph re-wrapped", v1.replace("Notice runs\nfrom the date", "Notice runs from the date"))

# the same re-issue under fixed windows, the rule the worker used before 12 September 2026
w1 = {chunk_hash(w) for w in dc.windows(v1)}
w2 = dc.windows(v2)
print(f"fixed windows: {len(w2)} windows, reused={sum(chunk_hash(w) in w1 for w in w2)}")
What you should see. revision 2: chunks=283 reused=281 embedded=2 ['preamble', 'NP-03']. swapped: chunks=283 reused=283 embedded=0 - a section's locator and hash move with it. a new section at the top: chunks=284 reused=283 embedded=1 ['WFH-01'] - one new chunk, nothing below it disturbed. re-wrapped: chunks=283 reused=283 embedded=0 - whitespace is collapsed before hashing. And fixed windows: 92 windows, reused=0: revision 2's new title line shifts every window, which is the sentence in _chunk's docstring, measured.

4 Count the calls before you make them

Medium

Rs 0. Copy batches from indexer.py and the packing loop of inspect_many from shared/pii.py, and run both per document over ACME's corpus: embedding calls, DLP requests, characters, and the rupees the embeddings would cost at the list rate.

  1. Keep the constants as the kit has them: 250 texts, 15,000 tokens, 3 characters a token, 400,000 bytes a DLP request.
  2. Batch and pack per document, as the worker does - it never sees two documents in one request.
  3. Price characters, not tokens: text embeddings are listed per 1,000 input characters. State the rate and where it came from.

Complete solution

python — Colab or a laptop
# Exercise 4 - count the calls before you make them (Rs 0; runs after exercise 1)
EMBED_BATCH, EMBED_TOKENS, CHARS_PER_TOKEN = 250, 15_000, 3        # services/ingest/indexer.py, lines 19-21

def batches(texts):                                                  # indexer.py, line 35 - copied
    out, cur, cur_tokens = [], [], 0
    for text in texts:
        tokens = max(1, len(text) // CHARS_PER_TOKEN)
        if cur and (len(cur) >= EMBED_BATCH or cur_tokens + tokens > EMBED_TOKENS):
            out.append(cur)
            cur, cur_tokens = [], 0
        cur.append(text)
        cur_tokens += tokens
    if cur:
        out.append(cur)
    return out

REQUEST_BYTES, SEPARATOR = 400_000, b"\n\n"                         # shared/pii.py, lines 45-46

def dlp_requests(texts):                                             # the packing loop of inspect_many(), pii.py line 81
    encoded = [t.encode("utf-8") for t in texts]
    i, n = 0, 0
    while i < len(encoded):
        parts, size, j = [], 0, i
        while j < len(encoded) and (not parts or size + len(SEPARATOR) + len(encoded[j]) <= REQUEST_BYTES):
            if parts:
                size += len(SEPARATOR)
            parts.append(encoded[j])
            size += len(encoded[j])
            j += 1
        n += 1
        i = j
    return n

USD_INR = 85
USD_PER_1K_CHARS = 0.000025    # Vertex AI pricing page, "Embeddings for text", online requests - re-verify before quoting it
calls = scans = chars = 0
for d in dc.load_documents("acme", EVALS, "documind-ai-YOUR-ID"):
    texts = [c["text"] for c in dc.chunk_document(d, "acme")]
    calls += len(batches(texts))
    scans += dlp_requests(texts)
    chars += sum(len(t) for t in texts)
print(f"acme: {chars:,} characters, ~{chars // CHARS_PER_TOKEN:,} tokens, {calls} embedding calls, {scans} DLP requests")
usd = chars / 1000 * USD_PER_1K_CHARS
print(f"embedding the corpus once: ${usd:.4f} = Rs {usd * USD_INR:.2f} at {USD_INR} to the dollar")
What you should see. acme: 2,064,459 characters, ~688,153 tokens, 57 embedding calls, 19 DLP requests - ten more embedding calls than the 47 one batched pass would need, because every document rounds up to at least one call, and nineteen DLP requests because the two biggest Acts need two and everything else fits in one. The price line is about $0.0516 = Rs 4.39. The rupee number is the smallest thing on the lane; Document AI's per-page charge on the PDFs is what a full corpus load actually costs (lesson 3.1).

5 Three vectors, then one document through the worker

Challenge

Needs a project; costs paise. In the notebook: embed revision 2's two changed chunks and PB-02 with text-embedding-005 on the regional client, validate the vectors with a copy of valid_vector, price them. In Cloud Shell: put a changed copy of the MSA through the deployed worker twice under one name and read reused and embedded off its ingest_ok lines.

  1. Set PROJECT_ID; authenticate (auth.authenticate_user() on Colab, gcloud auth application-default login elsewhere); the client is location="us-central1", never global.
  2. Request output_dimensionality 768 and task_type RETRIEVAL_DOCUMENT, exactly as embed_all does.
  3. Append a dated line to a copy of the MSA so its bytes are new (the same bytes would be a duplicate: the doc_key is the content hash), ingest it, append another line, ingest again under the same name.

Complete solution

python — Colab, COSTS MONEY
# Exercise 5a - three real vectors (COSTS MONEY: a fraction of a rupee; runs after exercise 3)
import math
from google import genai

PROJECT_ID = "documind-ai-YOUR-ID"
try:
    from google.colab import auth; auth.authenticate_user()
except ImportError:
    pass   # not on Colab: use `gcloud auth application-default login`

EMBEDDING_MODEL, EMBEDDING_TASK_TYPE, EMBEDDING_DIMENSIONS = "text-embedding-005", "RETRIEVAL_DOCUMENT", 768

def valid_vector(vector) -> bool:                                   # services/ingest/indexer.py, line 64 - copied
    return (vector is not None and len(list(vector)) == EMBEDDING_DIMENSIONS
            and all(math.isfinite(v) for v in vector))

chunks_v2 = dc.chunk_document(dict(doc, text=v2), "acme")
_, misses_v2 = plan_carry_over(chunks_v2, held)
texts = [chunks_v2[i]["text"] for i in misses_v2] + [next(c["text"] for c in current if c["locator"] == "PB-02")]

client = genai.Client(enterprise=True, project=PROJECT_ID, location="us-central1")     # embeddings are regional
response = client.models.embed_content(model=EMBEDDING_MODEL, contents=texts,
                                       config={"output_dimensionality": EMBEDDING_DIMENSIONS, "task_type": EMBEDDING_TASK_TYPE})
vectors = [list(e.values) for e in response.embeddings]
print("vectors:", len(vectors), "| dimensions:", sorted({len(v) for v in vectors}), "| all valid:", all(valid_vector(v) for v in vectors))
tokens = [getattr(getattr(e, "statistics", None), "token_count", None) for e in response.embeddings]
chars = sum(len(t) for t in texts)
print("tokens per text (the API's count, or the kit's chars // 3):", [int(t) if t else len(x) // 3 for t, x in zip(tokens, texts)])
usd = chars / 1000 * 0.000025      # per 1,000 input characters, Vertex AI pricing page - re-verify
print(f"{chars} characters: ${usd:.6f} = Rs {usd * 85:.4f}")
